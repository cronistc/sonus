# Módulo Menus — versão 1.0
Controle interno.

## O que é
A janela "Adicionar à playlist" (botão "+", criar playlist) e o menu "⋮" das músicas.

## Arquivos
`add.js` / `add.css` (adicionar/criar playlist) e `track-menu.js` (menu ⋮).

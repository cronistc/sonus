# Módulos do Sonus

Controle interno de cada parte do app. **Não aparece no app nem no GitHub**: para fora sai só a versão
(ex.: Sunshine Beta 1.1) e as melhorias descritas em texto. Cada módulo tem um `MODULO.md` com o que faz, os
arquivos e o histórico. X.Y: Y sobe a cada ajuste/novidade; X só quando o módulo for redesenhado.

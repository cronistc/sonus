# Sonus

Player de música para Android, feito do zero: interface própria, player de áudio próprio,
músicas via NewPipe Extractor, letras sincronizadas (LRCLIB) e downloads privados.

## Baixar

**[⬇ Baixar o Sonus (Android)](https://raw.githubusercontent.com/cronistc/sonus/updates/Sonus.apk)** — versão atual: 0.1.2

Instale o APK (o Android pede para permitir "instalar apps desconhecidos"). Depois disso o Sonus
se atualiza sozinho: na primeira vez ele pede uma autorização e, daí em diante, atualiza sem perguntar.
